# MockShot Website

Pure HTML/CSS marketing site. No frameworks.

## Structure

```
website/
  index.html
  privacy.html
  terms.html
  404.html
  style.css
  assets/
    favicon.svg
    mockup-1.png   ← replace with your app mockup
    mockup-2.png   ← replace with your app mockup
```

## Replace example mockups

Swap the PNGs in `assets/` keeping the same filenames:

- `mockup-1.png`
- `mockup-2.png`

They appear in the hero, Examples section, and Showcase grid.

## Preview locally

```bash
npx serve website
```

Or open `website/index.html` directly in a browser.
